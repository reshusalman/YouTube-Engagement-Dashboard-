# YouTube-Engagement-Dashboard

## Project Overview

This project presents an interactive YouTube Engagement Dashboard developed using Microsoft Excel.

The dashboard provides insights into YouTube video performance, audience engagement, views, likes, comments, video categories, and monthly engagement trends.

## Dashboard Features

- Total Views
- Total Likes
- Total Comments
- Average Views
- Average Likes
- Average Comments
- Engagement Rate
- Top Performing Videos
- Views by Video Category
- Likes and Comments Analysis
- Monthly Engagement Trend
- Video Performance Analysis
- Interactive Slicers

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Data Visualization
- Dashboard

## Dashboard

The dashboard provides insights into video performance and audience engagement, including views, likes, comments, categories, top-performing videos, and monthly engagement trends.

## Project Dataset

The project uses a YouTube video engagement dataset containing information about video titles, categories, views, likes, comments, engagement metrics, and other relevant data.

## Key Insights

- Identify the most viewed videos.
- Analyse videos with high audience engagement.
- Compare likes and comments across video categories.
- Track monthly engagement trends.
- Identify top-performing video categories.
- Understand overall YouTube engagement performance.
